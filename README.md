# Documentos Técnicos Diversos

Este repositório foi criado para reunir materiais técnicos de diferentes áreas, incluindo dúvidas, anotações, lembretes e resumos úteis para estudo e referência rápida. A ideia é manter um acervo organizado de conhecimento que possa ser consultado sempre que necessário.

## Conteúdo do repositório

- [Git](Git/Resumo%20GIT.md) — resumo de conceitos, comandos e boas práticas de Git e GitHub.
- [IA](IA/resumoia.md) — introdução a LLMs, modelos, agentes e MCP.
- [SSH](ssh/guia_ssh.md) — guia prático sobre autenticação por chaves SSH.
- [Docker](Docker/docker.md) — guia de estudos com comandos essenciais, Docker Compose, build de imagens, limpeza e boas práticas.

## Objetivo

Armazenar e organizar informações técnicas de forma simples e acessível, facilitando a revisão de temas importantes sem perder detalhes relevantes.
